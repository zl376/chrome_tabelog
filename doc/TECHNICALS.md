# Technical Details

## Architecture

```
tablecheck.com / omakase.in
        │  hover
        ▼
   content.js ──── instant loading tooltip
        │  chrome.runtime.sendMessage
        ▼
   background.js ─── 3-tier cache check
        │  chrome.runtime.sendNativeMessage
        ▼
   native_host.sh (wrapper, gitignored)
        │  source .venv/bin/activate
        │  exec python3 native_host.py
        ▼
   native_host.py
        │  curl_cffi (Safari TLS impersonation)
        ▼
   tabelog.com → parsed → fuzzy matched → score returned
```

### Cache tiers

| Tier | Storage | Lifetime |
|------|---------|----------|
| Content script memory | `Map` | Page session |
| Background memory | `Map` | Service worker lifetime |
| `chrome.storage.session` | Extension API | Browser session |
| `chrome.storage.local` | Extension API | Persistent (24h TTL) |
| Native host memory | Python `dict` | Process lifetime |

### Matching

`fuzzy-match.js` normalizes Japanese text (strips brackets, dividers, full-width spaces), then uses Levenshtein distance with substring containment as a tiebreaker. Threshold: 0.6 similarity.

### Why a native host?

Tabelog's Cloudflare blocks Chrome TLS fingerprints with 403. The extension's service worker and content script both use Chrome's network stack — both get blocked. A native host uses `curl_cffi` with Safari TLS impersonation to bypass the check. Chrome launches the native host on demand via the Native Messaging API; the process exits after each request.

### Wrapper pattern

`native_host.py` ships with `#!/usr/bin/env python3` — no machine-specific paths. `install.sh` generates `native_host.sh` (gitignored), a small wrapper that activates the project's `.venv` and runs `native_host.py`. Chrome's native host manifest points to the wrapper. This keeps the committed files clean.

## Configuration

All site selectors and matching rules are in `config.js`. If a site changes its markup, only this file needs updating:

- **`SITE_CONFIG`** — CSS selectors for finding restaurant blocks + name/location extraction functions
- **`TABELOG_CONFIG`** — Selectors for parsing Tabelog search results
- **`MATCH_THRESHOLD`** — Minimum similarity score for name matching (0.0–1.0)
- **`CACHE_TTL`** — Cache lifetimes (in milliseconds)

## Debugging

### Content script

To see which restaurant blocks are detected, run this in the page's DevTools console:

```js
const cfg = SITE_CONFIG[window.location.hostname];
document.querySelectorAll(cfg.restaurantSelector).forEach(el =>
    console.log(cfg.nameExtractor(el), el));
```

### Service worker

Check the service worker console for fetch and cache logs:

1. Open `chrome://extensions`
2. Find the extension card
3. Click the **service worker** link

### Native host

Test the native host directly:

```bash
echo -n '{"name":"らぁ麺や 嶋","area":""}' | \
  python3 -c "
import struct, sys
msg = sys.stdin.buffer.read()
sys.stdout.buffer.write(struct.pack('@I', len(msg)))
sys.stdout.buffer.write(msg)
" | python3 native_host.py | \
  python3 -c "
import struct, json, sys
raw = sys.stdin.buffer.read(4)
n = struct.unpack('@I', raw)[0]
print(json.dumps(json.loads(sys.stdin.buffer.read(n)), indent=2, ensure_ascii=False))
"
```

## Files

| File | Purpose |
|------|---------|
| `manifest.json` | Extension definition (MV3), stable extension key |
| `config.js` | Site selectors + Tabelog parsing rules |
| `background.js` | Service worker — cache + native messaging bridge |
| `content.js` | Content script — hover detection, tooltip UI |
| `content.css` | Tooltip styling |
| `utils/fuzzy-match.js` | Levenshtein matching with Japanese text normalization |
| `native_host.py` | Python native messaging host (auto-launched by Chrome) |
| `native_host.sh` | Wrapper script (gitignored, generated by install.sh) |
| `install.sh` | One-command setup script |
| `com.tabelog.proxy.json.example` | Native host manifest template |

## Privacy

This repo contains no personal identifiers. Machine-specific paths are templated and generated by `install.sh` at setup time. The extension key in `manifest.json` is a throwaway RSA key pair used only to pin the extension ID for native messaging.
